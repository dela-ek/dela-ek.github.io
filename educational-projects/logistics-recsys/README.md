# Logistics Recommender — Educational Demonstration

This reproducible project generates synthetic customer-item interactions and compares a popularity baseline with an item co-occurrence recommender using leave-last-interaction-out evaluation.

## Run

```bash
python scripts/run_experiment.py
```

Generated data is saved in `data/`; evaluation artifacts are saved in `output/`.

## Scope and disclaimer

This is an educational project using synthetic data. Results are illustrative and are not formal logistics, procurement, operational, or business advice. The system has not been validated for production deployment.
