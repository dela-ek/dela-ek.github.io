Executive summary.

Because no implementation existed for the earlier portfolio claim, this project was rebuilt as a transparent educational demonstration. A Random Forest reached 84.4% held-out accuracy and 0.844 macro-F1, compared with a 20% most-frequent baseline.

Question and data

Can summary features from simulated accelerometer and gyroscope windows distinguish lying, sitting, standing, walking, and stair activity? The generator creates 1,200 windows per class across simulated subjects, with overlapping distributions to avoid a trivial classification task.

Method

The workflow saves the generated CSV, creates a stratified 75/25 train–test split, and compares a most-frequent baseline with a scaled Random Forest pipeline. Outputs include JSON metrics, a confusion matrix, and a full classification report.

Interpretation and limitations

The model recovers the designed signal substantially better than the baseline, but the result only shows internal validity on data produced by the same simulator. It does not demonstrate patient-level generalization, device robustness, or clinical usefulness.

  • Synthetic windows do not reproduce real sensor artifacts or population heterogeneity.
  • The random split may share simulator assumptions across training and test data.
  • A real study would require subject-held-out validation, calibrated sensors, protocol review, and external data.
Educational disclaimer. This synthetic-data project is not a medical device and has not been clinically validated. It must not be used for diagnosis, patient monitoring, treatment, or formal health advice.
