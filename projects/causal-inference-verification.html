The default analysis uses the original Hillstrom email outcomes and Card fast-food interviews. Packaged inputs and raw downloads each have recorded SHA-256 hashes.

What the checks verify

  • Original sample sizes, binary observed outcomes and treatment-arm labels.
  • All 410 policy-study source rows remain identifiable despite one reused sheet number.
  • Estimator identities and explicit assumptions.
  • A fresh offline run reproduces numerical metrics, every result CSV and the text report.

The GitHub workflow runs tests and reproduction on Python 3.11 and 3.12. The repository and detailed CI logs remain private; request access through the case study. Passing checks establish software reproduction, not the validity of parallel trends or state-level policy inference.
