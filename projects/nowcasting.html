Nowcasting stock-market movements with a recurrent model

Executive summary.

The corrected pipeline builds lagged market features, trains a GRU-based model, and saves the fitted model, information-set builder, predictions, and metrics. Validation MAE was 0.00962; on a separate 511-row evaluation file, MAE was 0.01762.

Question

Can a compact recurrent model learn short-horizon structure from a reproducible set of lagged market variables? The project is framed as a modeling exercise—not as a trading strategy or evidence of investable performance.

Data and method

The repository includes generated training and evaluation market series. A fitted information-set builder produces 13 model inputs. The neural network uses a 64-unit GRU layer followed by a 32-unit dense layer; seeds and artifacts are recorded so the experiment can be rerun.

  • Training pipeline separates data generation, feature construction, training, and evaluation.
  • Saved outputs include validation and evaluation predictions.
  • Metrics are reported on normalized target scale and should be interpreted only in that context.

Results

0.00962Validation MAE · 313 rows
0.000140Validation MSE
0.01762Evaluation MAE · 511 rows
0.000641Evaluation MSE

The higher error on the separate evaluation series is the more important finding: performance changes outside the validation window, reinforcing the need for rolling, regime-aware evaluation.

Limitations and next steps

  • The market data in this repository is generated for workflow testing, not a licensed live-market feed.
  • No transaction costs, slippage, benchmark strategy, or economic-value backtest is included.
  • Next steps would require walk-forward validation, stronger baselines, prediction intervals, and regime analysis on appropriately licensed data.
