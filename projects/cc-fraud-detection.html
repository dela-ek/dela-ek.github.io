Executive summary.

After removing duplicate rows, the benchmark compared a prior baseline, class-balanced logistic regression, class-balanced random forest, and Isolation Forest. Random Forest ranked first by average precision at 0.867 and produced F1 of 0.841 on the development split.

Corrections made

The earlier runner used a machine-specific path, duplicated one anomaly model, suppressed warnings, and emphasized ROC AUC without fully addressing imbalance. The revised experiment uses repository-relative paths, consistent duplicate removal, class weighting, pipeline-contained scaling, fixed seeds, structured JSON metrics, and average precision for model selection.

Evaluation design

The fixed development set contains 97 fraud rows among 56,277 records after deduplication. Supervised scores use a 0.5 classification threshold. Isolation Forest is trained only on legitimate training rows and uses a documented high-score quantile threshold.

Random Forest offers the strongest precision–recall balance in this split, while logistic regression catches more fraud at the cost of many more false positives. A real system would tune thresholds using review capacity and error costs rather than accept the default threshold.

Limitations

  • A single fixed development split does not measure temporal drift.
  • Transaction features are anonymized, limiting causal or operational interpretation.
  • No cost-sensitive threshold optimization, latency test, fairness audit, or production monitoring is included.
