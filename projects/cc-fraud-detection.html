Executive summary.

After removing duplicate rows, the benchmark compared a prior baseline, class-balanced logistic regression, class-balanced random forest, and Isolation Forest. Random Forest ranked first by average precision at 0.867 and produced F1 of 0.841 on the model-selection split.

Modeling approach

The benchmark combines consistent duplicate removal, class weighting, pipeline-contained scaling, fixed seeds, and structured evaluation metrics. Average precision guides model selection because fraud cases represent a small fraction of transactions. Comparing supervised classifiers with an anomaly detector makes the precision–recall tradeoffs explicit.

Evaluation design

The fixed model-selection set contains 97 fraud rows among 56,277 records after deduplication. Supervised scores use a 0.5 classification threshold. Isolation Forest is trained only on legitimate training rows and uses a documented high-score quantile threshold.

Random Forest offers the strongest precision–recall balance in this split, while logistic regression catches more fraud at the cost of many more false positives. Precision and recall expose the tradeoff between investigation workload and missed fraud at the documented thresholds.

Evaluation scope

  • A single fixed model-selection split does not measure temporal drift.
  • Transaction features are anonymized, limiting causal or operational interpretation.
  • No cost-sensitive threshold optimization, latency test, fairness audit, or production monitoring is included.
Result context. This is an offline classification benchmark. Metrics describe the fixed model-selection split; they do not measure production transaction outcomes.
