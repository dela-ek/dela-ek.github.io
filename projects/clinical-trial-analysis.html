Executive summary.

A baseline-adjusted ANCOVA estimates a synthetic treatment effect of −3.207 units, with HC3 95% interval [−4.109, −2.306]. The known simulated effect is −3.0. Missing-outcome sensitivity is reported separately.

Question and data

How sensitive is a randomized trial estimate to baseline imbalance and missing outcomes?

The study generates 1,200 randomized participants, a continuous baseline measure, four sites, and a follow-up outcome in arbitrary units. Outcome availability depends on baseline and treatment assignment; 912 follow-up outcomes are observed. Hidden complete outcomes are used only to audit the simulation.

Pipeline and evaluation

The primary model regresses observed follow-up on assignment, centered baseline, and site indicators. HC3 sandwich covariance accounts for heteroskedasticity. A complete-case unadjusted comparison is the baseline. A pattern-mixture sensitivity analysis predicts missing outcomes from the observed-data model, shifts missing treatment-arm outcomes by delta, and refits the point estimate.

The unadjusted observed-outcome estimate is −4.105 units, compared with adjusted −3.207. For delta from −8 to +8, adjusted sensitivity point estimates range from −5.683 to −0.732. The complete-data simulator audit estimates −2.899; it is not an available real-study analysis.

Assumptions and limitations

Complete-case adjustment requires a correct conditional mean and follow-up availability independent of the outcome given modeled covariates and assignment. Sensitivity uses conditional-mean imputation, not multiple imputation, and supplies no imputation-based interval. The synthetic outcome has no clinical meaning; no efficacy or treatment recommendation is supported.

Reproducible delivery

Importable Python modules separate configuration, data validation, domain-specific transformations, modeling or estimation, evaluation, artifact persistence, and reporting. The command-line entry point reproduces the full study with documented dependencies and seed 42.

The private repository includes mathematical and data-contract tests, a data fingerprint, configuration and library versions, machine-readable metrics, result tables, and the evaluation report. CI runs Python 3.11 and 3.12 and checks that a fresh run reproduces the saved outputs.

Code access. Source code, the full analytical design, and detailed verification logs are available on request. The project repository is private.
