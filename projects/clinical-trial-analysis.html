Executive summary.

Baseline-adjusted 96-week CD4 analysis, HC3 uncertainty and explicit sensitivity to missing trial outcomes. adjusted difference · CD4 cells/mm³: 66.2; missing 96-week outcomes: 38.0%.

Question and real data

What is the observed 96-week CD4 difference between randomized ZDV+ddI and ZDV arms, and how sensitive is it to missing outcomes?

  • ACTG 175 randomized HIV trial, CRAN speff2trial distribution

    Original 2,139 participants. Analysis preselects arms 0 (ZDV) and 1 (ZDV+ddI), 96-week CD4 endpoint cd496, baseline cd40, age, and prior-antiretroviral stratum. Missing follow-up remains missing; no postrandomization predictors.

Pipeline and evaluation

ANCOVA adjusts for baseline CD4, age and original prior-antiretroviral stratum; these are preassignment variables. HC3 sandwich uncertainty is reported alongside an unadjusted complete-case comparison. A pattern-mixture analysis imputes conditional means for missing outcomes, shifts only missing treatment-arm outcomes by a stated delta, then refits. The sensitivity curve gives point estimates, not multiple-imputation intervals.

Assumptions and limitations

Randomization does not make complete-case outcomes unbiased when follow-up is missing. Conditional ignorability and mean-model adequacy remain assumptions. Delta values are scenarios in CD4 cells/mm³, not observed effects. Trial strata are not sites. Treatment discontinuation, death and clinical-event mechanisms require a fuller estimand strategy. This historical educational reanalysis is not medical guidance or an efficacy recommendation. Cite ACTG 175 and the CRAN speff2trial data distribution; preserve their attribution and terms.

Reproducible delivery

The Python package separates verified data loading, domain transformations and estimators, analysis orchestration, result tables, scientific figures and reporting. Offline reproduction uses immutable real inputs; source acquisition and preparation scripts separately verify checksums. Current reference outputs contain actual observations and estimates.

Tests check source contracts, mathematical behavior and evaluation boundaries. The repository workflow tests Python 3.11 and 3.12, reruns the analysis and compares input fingerprints, metrics, tables and reports. Detailed source and CI logs are available on request.
