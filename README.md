# Dela Akpalu — Data Science & Statistics Portfolio

[Explore the portfolio](https://dela-ek.github.io/) · [LinkedIn](https://www.linkedin.com/in/edakpalu/)

I use Python, R, and SQL for reproducible analysis, statistical modeling, and machine learning. My background includes an M.S. in Statistical Science from Wake Forest University, a master's in Data Science from AIMS, and a Wake Forest Data Science Certificate.

## Selected work

| Project | Methods and evidence | Case study |
| --- | --- | --- |
